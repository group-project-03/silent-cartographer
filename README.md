# Silent Cartographer: Maze Navigation 
uses classical search methods & reinforcement learning to create a blind intelligent agent that can navigate unknown 64x64 mazes with dangers. Despite incomplete knowledge and environmental risks, the agent effectively explores, creates an internal map, and develops the best solutions.


# Instructions:

## Requirements:
- Python >= 3.7
- NumPy
- Pillow (PIL)
- Matplotlib 
- PyTorch

## Run the script:
	python silent_cartographer.py
